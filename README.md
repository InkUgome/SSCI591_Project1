# SSCI 591 Project 1



This is my Project 1 website for SSCI 591: Web & Mobile GIS at USC. I created a personal GIS portfolio to introduce my background and share some of my GIS work.

The website includes:

- My education and GIS background

- A GNSS elevation analysis project from Catalina Island

- A Bird Explorer using observation data from iNaturalist

- An interactive map built with Leaflet

## Tools

- HTML

- CSS

- JavaScript

- Leaflet

- iNaturalist API
